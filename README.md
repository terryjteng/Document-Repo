# Document Hub

A React single-page document library built with Vite. It includes searchable
table, board, and gallery views, document editing, taxonomy management, and
browser-local persistence.

## Run locally

```sh
cd hub
npm install
npm run dev
```

Run `npm run build` in `hub/` to create a production build. The included
records are fictional demo data. Changes are saved in the current browser's
local storage; this starter does not include a shared database or account
integration.
